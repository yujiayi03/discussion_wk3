## Part One: HTML

*The first order of business is to create content for the site:*

* Create a new html file, name it after yourself \[your\_name.html\]  
* Generate some HTML content for the page  
  * You can use \! \+ tab to fill in the template of your new file  
  * Or you can copy over from one of your other files  
  * Make sure you have [landmark](https://www.w3schools.com/accessibility/accessibility_landmarks.php) tags(\<header\>, \<main\>, \<footer\>, \<nav\>)  
* Update the [navigation](https://www.w3schools.com/tags/tag_nav.asp) of the site to include your new html file

## Part Two: CSS

*Now that we have our pages, it's time to style:*

* Inside the css folder, you need a reset.css file and a style.css file  
  * The reset.css can be taken from HW1, this file can be used and reused for all assignments  
    * This repo currently has a html5reset.css page, this works\!  
  * The style.css file should be blank to start  
* Link your stylesheets to all html files  
  * Remember, the order which you link the sheets matters  
  * File names are **case sensitive**  
  * Double check your [file paths](https://www.w3schools.com/html/html_filepaths.asp)

*Tip \- If you don’t know how to do something, Google is your friend\!*

* Within style.css:  
  * Style the background  
    * Give the site a new background color  
  * Style the text  
    * Change the font  
    * Make your headers bold  
    * Change the color  
  * Style your images  
    * Customize the height and width  
    * Put a border around your images  
  * If you have time add other styling  
* Validate your pages to ensure accessible styling

*As a group, let's come together to check out Inspect Element and different display properties.*
